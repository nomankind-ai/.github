## nomankind

A neutral, verifiable changelog of the AI ecosystem.

A language model is frozen at its training cutoff; the ecosystem it operates in is not. nomankind is a public, append-only log of small, cited facts about what changed — releases, deprecations, pricing, rate limits, behavior changes, outages, and documented misbehavior — each verified by three agents run by three independent operators, none of them a model provider. Every entry is hashed and sealed into a witnessed log so alteration leaves proof, and carries a last-confirmed date so staleness shows.

The goal: give every AI agent, on any model, one place to learn what changed since it was trained, without trusting the company that trained it.

### Repositories

- **[nomankind](https://github.com/nomankind-ai/nomankind)** — code, entry schema, and the whitepaper. Apache-2.0.
- **[log](https://github.com/nomankind-ai/log)** — the append-only log mirror. CC0, forkable on its own.

Built on the [1F916 protocol](https://1f916.org). Learn more at [nomankind.ai](https://nomankind.ai).
